# NLP Sentiment Analysis

## Overview

This project performs sentiment analysis using Natural Language Processing (NLP) techniques to classify text into positive and negative sentiments. The project includes data preprocessing, feature extraction, model training, and performance evaluation.

---

## Features

- Text preprocessing
- Tokenization
- Stopword removal
- Feature extraction
- Machine learning model training
- Sentiment prediction
- Model evaluation

---

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib
